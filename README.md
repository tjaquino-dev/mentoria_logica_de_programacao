# 🚀 Mentoria de Lógica de Programação

Repositório criado para registrar minha jornada de estudos em lógica de programação, algoritmos, Python, estruturas de dados, banco de dados e desenvolvimento de software.

---

# 🎯 Objetivo

Construir uma base sólida em programação, aprendendo a resolver problemas através de algoritmos antes de focar em linguagens e frameworks.

A proposta desta mentoria é priorizar:

✅ Entendimento antes da memorização

✅ Raciocínio antes do código

✅ Fundamentos antes da complexidade

✅ Documentação contínua da aprendizagem

---

📄 `docs/metodo-de-aprendizagem.md`

---

# 🧠 Metodologia de Resolução de Problemas

Todo exercício é analisado seguindo o modelo:

```text
ENTRADA
↓
PROCESSAMENTO
↓
DECISÃO
↓
SAÍDA
```

Somente após essa análise o problema é transformado em algoritmo e posteriormente em código.
