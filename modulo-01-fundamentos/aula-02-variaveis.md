# Aula 02 - Variáveis e Tipos de Dados

## Objetivo

Compreender o que são variáveis, como armazenam informações e como identificar corretamente os principais tipos de dados utilizados na programação.

---

## Conceitos

### Variável

Uma variável é um espaço utilizado para armazenar informações temporariamente durante a execução de um programa.

Exemplos:

- nome
- idade
- salario
- preco

---

### Nome e Valor

Toda variável possui:

- Nome
- Valor

Exemplo:

idade = 35

Nome:

idade

Valor:

35

---

## Principais Tipos de Dados

### int

Representa números inteiros.

Exemplos:

- 10
- 25
- 100
- 2026

---

### float

Representa números decimais.

Exemplos:

- 1.75
- 5.5
- 99.90

---

### str

Representa textos.

Exemplos:

- "Thomaz"
- "Python"
- "São Paulo"

---

### bool

Representa resultados lógicos.

Valores possíveis:

- True
- False

---

## Descobertas Importantes

CPF parece um número.

Porém não é utilizado para cálculos.

Portanto:

CPF → str

O mesmo raciocínio vale para:

- RG
- CEP
- Telefone
- Matrícula
- Placa

---

## Boas Práticas

Antes de escolher um tipo de dado, faça as perguntas:

1. Vou realizar operações matemáticas?

Se sim:

- int
- float

2. É apenas uma identificação?

Se sim:

- str

---

## Tome Nota

Principais tipos utilizados no início da programação:

- int
- float
- str
- bool

---

## Tome Nota e Grife

Nem tudo que parece número deve ser armazenado como número.

Identificadores normalmente são armazenados como texto.

Exemplos:

- CPF
- RG
- CEP
- Telefone
- Matrícula
- Placa
